# 问题3：默认分类器比较

本题沿用第一题的3600例训练集和1200例测试集，不进行标准化，使用scikit-learn 1.9.0中的逻辑回归、决策树、KNN和SVC默认参数，仅为支持random_state的模型固定种子20261022。实际配置、全部预测、逐类指标及警告记录保存在q3_runs/20261021_111602_87b2fd。助手已重新从保存的预测计算指标并核对混淆矩阵，均一致；本次训练未捕获警告，逻辑回归迭代82次，SVC的fit_status为0。这些记录未显示求解失败，但不意味着模型一定具有良好的泛化能力。

如图3-1所示，Accuracy与macro-F1给出的模型排序完全一致，均为SVC、KNN、逻辑回归、决策树。其中SVC正确分类954例，KNN正确分类874例，Accuracy相差6.67个百分点，macro-F1相差约0.0717；两项指标共同表明SVC在本次固定划分和默认配置下总体表现最好。四个模型均超过第二题常数预测的Accuracy 0.315833和macro-F1 0.048005，说明它们在这批测试数据上实现了比单纯预测多数类更好的分类。但所有模型的macro-F1都低于各自Accuracy，结合逐类结果可见，各模型对样本较少类别的识别仍不充分。两项指标的数值差距不能直接当作偏差程度的统一度量，因为其定义和聚合方式不同。

图3-2进一步显示，总体排名一致并不意味着各类表现也完全一致。SVC对类别0的F1为0.8790、Recall为0.9393，而类别9的F1仅0.4211、Recall为0.3077。KNN的类别9 F1为0.4571，反而高于SVC：两者都识别对26例中的8例，Recall同为0.3077，但KNN共预测9例为类别9，Precision为8/9=0.8889；SVC共预测12例为类别9，Precision为8/12=0.6667，因此SVC在该类有更多误报。逻辑回归对类别6只识别对56例中的3例，Recall为0.0536、F1为0.0882；决策树虽然总体落后于逻辑回归，在类别6却有更高的Recall 0.2679和F1 0.2362。这说明评价不能只选一个总体指标，也应检查具体类别的漏报和误报。

从机制上看，默认逻辑回归使用线性判别结构，而本次数据每类包含两个簇；线性边界可能不足以刻画部分类别之间的关系。RBF核SVC能表达非线性边界，KNN基于局部邻域，两者较高的测试分数与这种机制解释相容，但本次没有专门控制非线性程度，不能把性能差异全部归因于非线性。默认决策树不限制最大深度，具有较强拟合能力，可能受训练样本扰动和噪声影响；然而本题没有报告训练分数或深度验证曲线，因此尚不能把最低测试分数直接认定为已经证实过拟合。此外，当前未标准化，KNN和SVC受到距离或核函数尺度的影响，下一题将单独比较标准化前后表现。

本次结果支持“在当前数据、划分与默认配置下，SVC的总体表现最好，但并非每个类别均最好”的结论，而不能支持“SVC普遍优于其他算法”。类别9的测试集仅26例，其Recall每变化1个正确样本约变化3.85个百分点，少量样本变化即可影响该类评价；本题没有重复划分或交叉验证误差条，不能将模型间差异直接解释为统计显著。后续继续固定实验数据、同时报告Accuracy与macro-F1，并用训练集内部验证研究参数和不平衡处理，不使用本次测试排名反复选择超参数。
