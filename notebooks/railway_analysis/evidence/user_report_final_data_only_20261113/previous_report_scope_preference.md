## 后续写作与排版约束

- 数据采集和补采是问题1的准备与质量控制，正文简写，不按聊天或调试过程逐轮叙述。
- 采集部分原则上使用一小段方法与来源说明、一张最终质量汇总表，并按课程要求保留必要的核心采集/矩阵构建代码及对应实际运行输出。
- 不将每轮补采、每次报错、每个断点恢复、每个阶段编号都展开成正文小节或重复截图。
- 完整脚本、原始响应、来源清单和清洗日志保存在复现实验文件；附录只收纳确有必要的补充材料，避免将全部调试记录堆入附录。
- 问题1的正式内容重点是研究口径、节点与站点定义、最终时间矩阵及质量图、特殊地区和缺失处理、方法局限。
- 整份报告的主要篇幅留给MDS/t-SNE/UMAP结果、参数敏感性、质量指标、聚类对比与真实证据分析。
- 不因压缩采集篇幅而省略必要来源、不可达与缺失的区分、关键方法限制、核心代码和对应输出。
- 仅在用户明确确认材料全部发送、数据与分析核验完成后才生成DOCX；R绘图和排版由助手负责，用户接收代码TXT并回传实际运行截图。
