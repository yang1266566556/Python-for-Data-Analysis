## 结果边界

- 日期从11月10日首程出发，行程最长96小时，到达必须早于11月15日00:00；不能将一天的车次复制到次日。
- 同站换乘最低30、60、90分钟只是敏感性分析假设，尚未核实为官方最低换乘要求。保留实际等待时间，并通过门槛筛选；等待不重复计费。
- 配对以实际车站代码相同为必要条件，不将同城不同站当作零时间连接。
- 相同车次名称不充分识别同一班列车；以内部车次号和列车始发日期辨识同一服务的候选，两段继续乘坐同车的情况另表留待直达核验，不混入两班换乘结果。
- 日期查询缺失时，代码禁止输出“最优”数值，只保留已采集配对供排查。查询完整也不代表所有线路或所有中转站完整。
- 此处“完整日期查询”指指定X11—X14请求正常返回（包含成功空返回），并不保证官方响应包含全部车次。
- 父运行和新查询采集时刻不同，属于同一冻结研究日期范围的不同快照，时刻表可能更新。来源时间保留，后续正式矩阵需统一快照及更新策略。
- 珠海/横琴查询仅用于接入来源核验，未计算澳门接驳时间。即便这些方向有列车，也不意味着完成澳门跨系统、步行及通关的行程核验。
